SteuerungControls

Desktop bevorzugt Tastatur + Maus, Mobile nutzt Joystick + 3 Buttons. Beide steuern dieselben Aktionen — Maus/Touch bestimmt zusätzlich die Ziel- bzw. Blickrichtung.

Desktop favors keyboard + mouse, mobile uses a joystick + 3 buttons. Both trigger the same actions — mouse/touch also sets your aim/facing direction.
